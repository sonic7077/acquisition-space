# 多平台选题库说明

## 页面和搜索流程

素材列表放在第一块，默认显示全部（包括未达可用条件、已采用、已排除），默认按点赞降序。可切换真实来源平台及点赞、评论、发布时间、入库时间排序。来源与采集渠道分开，手工录入的小红书内容仍归入小红书来源；其他平台来源可以手工登记并筛选。

下方关键词搜索支持同时勾选抖音、小红书、视频号。1至5个关键词，每词最多100字。IP可留空；最低点赞、时长默认0，只决定可用素材视图，不阻止入库和评论采集。未知数值显示未知，不冒充实际0。

每词每平台1至5页，每平台最多尝试1至20条作品（总上限，跨关键词共享），每条成功入库作品自动读取1至5页一级评论。视频号先从搜索的exportId读取详情，取得明文objectId和作者后请求评论，不将加密媒体地址或decode_key保存为原始来源。小红书包含图文及视频笔记。没有实现无限历史采集或所有二级回复。

评论在同一任务内自动入库，不需要再次点击采集评论；列表显示数量、入库中、失败或本次页数已完成且仍有更多评论。平台失败不阻断其他平台，评论失败保留作品和其他成功结果；手动重试会按原范围再次调用并去重，可能计费。预算不足显示部分完成。已排除状态保留，重复命中的关键词合并，跨平台相同ID不会混为一条。

## IP可选与权限

未归属的素材、博主、评论及任务按提交者隔离。管理员可见，团队长仅可见当前本团队成员的未归属数据，队员仅本人；具有IP的记录继续使用原IP授权，不改变知识库、稿件权限。未归属素材加入写稿时选择已授权IP，稿件归到目标IP，原素材仍在未归属池。默认顶部“全部授权IP”可看到可访问的未归属记录；顶部切换某IP后只展示该IP记录。

自动飞书同步继续先博主、再作品、再评论。未归属同步只镜像任务提交者自己的素材池；未归属IP列为空。飞书Base、字段映射和冲突保护沿用原实现。

## 爆款参考公式

参考倍数 = 当前作品点赞数 / 同作者、同平台、当前归属范围内已采作品点赞中位数。至少3条有效点赞样本才计算，未知点赞不计入样本，基线为0时不计算倍数。中位数样本包含当前作品。该指标仅说明已采样本内的相对表现，不代表博主全部历史平均，不代表流量、成交或平台官方爆款结论；当前没有固定的爆款倍数阈值。关键词、采集范围和上游排序都会影响样本。

## 官方协议和调用预算

2026-11-17读取TikHub官方OpenAPI：https://api.tikhub.io/openapi.json 。新增协议摘要保存在references/TikHub/多平台接口-2026-11-17.json，不包含凭证。

| 平台 | 用途 | 方法与路径 |
| --- | --- | --- |
| 小红书 | 搜索笔记 | GET /api/v1/xiaohongshu/app_v2/search_notes |
| 小红书 | 笔记评论 | GET /api/v1/xiaohongshu/app_v2/get_note_comments |
| 视频号 | 搜索作品 | POST /api/v1/wechat_search/v2/fetch_search_videos |
| 视频号 | 取得评论所需objectId及作品信息 | POST /api/v1/wechat_channels/v2/fetch_video_detail |
| 视频号 | 一级评论 | POST /api/v1/wechat_channels/v2/fetch_video_comments |

抖音沿用已接入的搜索V1、作品评论及可选作者详情。视频号显式raw=false，并用Python整数解析后转字符串保留64位ID，不经过JS Number。

调用上界 = 关键词数×每词页数×平台数 + 每平台作品上限×（评论页数×平台数 + 视频号详情开关 + 抖音作者详情开关）。错误请求同样计入全系统共享日预算；实际费用按TikHub账单。达到作品尝试上限后停止该平台后续搜索，故真实调用可少于估算。

## 验证和限制

53项后台测试、7项浏览器验收通过，TypeScript与生产构建通过。测试包括多平台链路、评论自动入库、分页、ID精度、预算边界、部分失败继续其他平台、未归属权限、写稿选IP、未归属飞书隔离和基线公式。页面截图为隔离测试数据。

新增小红书/视频号适配依据官方协议与受控响应验证，尚未使用本机真实Key发起这些平台的付费搜索。实际账号权限、额度、可见字段和返回质量由TikHub与来源平台决定；缺失字段显示未知。平台接口结构如有变化，会显示任务错误，不把未取得的数据伪装为成功。首帧视频生成保持撤下状态。
