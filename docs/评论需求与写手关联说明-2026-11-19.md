# 客户线索与写手关联使用说明

1. 在选题库搜索素材时，系统会采集一级评论。在客户线索按博主、作品查看评论和咨询记录。
2. 展开「评论分类与有效需求标准」查看判定规则。可按评论类型、咨询意向筛选，也可勾选「仅看有效需求」。
3. 在有效需求记录上点「转为选题」。确认目标 IP，填写题目后创建待写稿，稿件保留原话和来源快照。未归属线索可在建稿时选择有权限的目标 IP。
4. 在调用写手、改编稿件或创建内容任务时，也可直接选用同 IP 或有权限查看的未归属有效线索。

## 分类与统计

- 内容类型按需求、反对、追问、共鸣的顺序判断，主要依据个人情境、求助、质疑和提问表达。信息不足或疑似推广记为待核实。
- 咨询意向先排除明显质疑、推广和否定，再判断问价格、要资料、问方案。陈述型求助、个人情境与具体保险信息组合也可判为问方案。
- 有原话、意向是问价格、问方案或要资料，且评论类型为非反对，即进入有效需求。记录数按评论或咨询计算。人工核实联系路径后再跟进。
- 系统读取时会采用新规则。点击「本地重分析评论」也可重新保存规则结果，重采和重分析均保留人工修正。

## 证据与权限

旧需求库链接会打开客户线索。已有稿件继续保留历史需求引用。查看人无权访问来源时，稿件隐藏该来源的评论证据。

原话帮助写手理解选题和客户表达。价格、案例、资质等事实以已核验的知识库资料为依据。评论分类使用本地规则，写作任务使用系统设置中的模型配置。
