# AI 写手进化 · 获客空间版

系统直接读取本目录的八份 `SKILL.md`。在「IP与写手」可查看默认写手，在选题库素材中可点「调用写手」，审稿时可点「用写手改编」或「用辅助写手分析」。

| 技能 | 在系统中的用途 |
| --- | --- |
| `short-video-writer` 原创口播 | 围绕一个真实问题写一条可朗读口播 |
| `viral-rewrite-writer` 复刻口播 | 从已确认逐字稿拆解结构，用自己的证据和表达改写 |
| `gzh-article-writer` 公众号 | 用分析、事实和建议重组同题长文 |
| `tietu-writer` 图文贴 | 抽取同题的一个搜索问题，安排首图正文与配图 |
| `moments-writer` 朋友圈 | 提炼一个态度、观察或可执行建议 |
| `customer-needs-miner` 客户需求挖掘 | 从有权限的评论或脱敏语料提取需求和选题建议 |
| `ip-writer-skill-builder` IP 写手初始化 | 整理六类输入和 12 问的填写依据，给出专属写手草案 |
| `writer-self-evolve` 写手进化 | 根据手改对照和已提供的复盘证据提出规则候选 |

## 从素材到稿件

- 用「原创口播」写自己的选题。手里有一条已确认逐字稿时，可以用「复刻口播」沿用标题逻辑、开头和段落功能。素材和审稿入口要求确认逐字稿。涉及同一主题的四个文体可以按「口播 → 长文 → 图文贴 → 朋友圈」逐步改编，也可以独立创作。
- 共享知识导入只选末级目录。写稿和改稿先选目标 IP 与写手，再用「预览上下文」核对匹配的知识。原作品评论用于拆解反馈，需求库用于理解目标 IP 的用户，事实以适用于本题的已核验、未过期资料为准。原稿或对标的数字需要对应的知识出处。
- 在「IP与写手」新建专属写手并填写 12 问。行业样例用于参考填法，未知事实仍需核实。填写后点击「生成 / 更新 SKILL」，由团队长或管理员启用。新任务用本次所选文体，沿用专属写手已启用的身份和语感。要更新已保存或下载的专属 SKILL 文体参考，需重新生成并启用。

## 用四类反馈调整写手

| 反馈 | 系统里怎么用 |
| --- | --- |
| 人工改稿 | 保存新版本，在审稿中选择真实前后对照运行「写手进化」。同一改法至少出现在三篇独立根内容，才有资格作为学习规则提交审核 |
| 平台数据 | 在「数据复盘」按平台查看指标，分析时提供同平台、同口径和同观察期的数据与对应文案。把观察写成一条待验证的规则候选 |
| 语料过期或缺失 | 在知识库补来源、日期和适用范围，核验后进入下次检索。事实更正更新知识，具体表达习惯才进入写手规则 |
| 业务或受众变化 | 更新产品、客户需求与目标 IP 配置，再核对写手 12 问和结尾落点 |

从辅助分析报告中选择有证据的建议，提交候选并由团队长或管理员人工采纳。默认写手的增强按 IP 生效，专属写手采纳语感后重新生成并启用。复盘可以比较人工改稿量、未改通过的篇数和近期需要补的知识。

手工发起复盘可使用[提炼提示词](writer-self-evolve/references/提炼提示词.md)，再用[规律库模板](writer-self-evolve/references/规律库模板.md)记录证据和采纳版本。

独立使用时，将相应 `SKILL.md` 和必要的授权资料交给写手。语料先脱敏，涉及内部产品、客户或语感的资料按共享范围整理。
