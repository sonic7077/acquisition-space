# 写手反馈记录与每周复盘模板

在「IP与写手 → 规则与知识增强」或专属写手的「语感规则」登记。下列表格可作为人工核对记录和每周复盘底稿。

## 候选规则

| 字段 | 填写方法 |
| --- | --- |
| 目标 IP、写手、平台或文体 | 写清适用范围。跨文体偏好也需明确所属 IP。 |
| 规则和对照 | 一条规则只说一个动作。写明「在什么位置、满足什么条件、怎么写」，附一组改前 → 改后例句。 |
| 来源 | 真实改稿学习、人工表达偏好、共享知识支持的业务补充，或发布数据产生的试验假设。 |
| 证据 | 标注前后稿件 ID、独立内容根、分析报告 ID、知识 ID 或同口径平台数据。 |
| 状态 | 待观察、待审核、已采纳、已归档。由人工记录审核人、日期和生效版本。 |

学习类候选需要同一种改法在至少 3 篇独立根稿件中发生，同一作品的多份版本合并。固定换词与禁词可单列作审稿检查建议；事实更正写入共享知识待核。发布数据支持的结论保留为试验假设。

| 适用范围 | 规则 | 改前 → 改后 | 证据 | 建议动作 |
| --- | --- | --- | --- | --- |
| 本 IP 的短视频口播 | 收尾直接落到一个具体动作 | 「大家一定要重视」 → 「先把现有保障列在一张表上」 | 稿件 A、B、C，3 个独立根 | 提交学习规则候选，请团队长或管理员审核 |

## 每周复盘

| 项目 | 记录内容 |
| --- | --- |
| 改稿量 | 观察日期、独立内容数、零改动数、上期和本期可比改稿量。沿用相同方法，无法计算时写明原因。 |
| 新候选 | 最多 3 条，附改前、改后和独立证据。 |
| 发布表现 | 同平台、同账号、同观察窗口内效果较好和较差的稿件，引用段落，并列可能影响。 |
| 知识材料 | 哪些案例重复、数字过期或缺出处，哪些已补核验资料。 |
| 新需求和业务变化 | 证据编号、适用范围、需要更新的知识或写手配置。 |
| 待决策 | 最多 3 项，写出建议和本周单项试验计划。 |
| 版本变更 | 记录采纳、合并、归档或回退及原因，保留审核人、日期和版本。 |
