# 默认8个写手与知识增强

## 默认能力

无需先创建写手或填写12问，即可调用分享包对应的8个默认写手。基础模板只读，默认ID稳定，多次启动不会重复创建；原有专属写手与12问保留。

| 默认写手 | 输出 |
| --- | --- |
| 客户需求挖掘写手 | 需求分析报告 |
| IP写手初始化写手 | 12问与配置建议 |
| 复刻口播写手 | 独立待审稿 |
| 原创口播写手 | 独立待审稿 |
| 公众号写手 | 独立待审稿 |
| 图文贴写手 | 独立待审稿 |
| 朋友圈写手 | 独立待审稿 |
| 写手进化写手 | 改稿分析与候选规则建议 |

辅助报告不能直接批准为发表稿。初始化建议不自动创建身份，进化建议不自动采纳为规则。

## 从素材调用

在选题库每条素材中点击“调用写手”，选择有权限的目标IP和默认/专属写手，可附同作品评论、需求和任务要求。未归属素材明确选择目标IP后可调用，不会因此自动改变原素材归属。已归属素材只能调用本IP写手。

先预览或导出提示包，再提交写手任务。预览不调用模型；提交使用管理员系统设置中的现有模型配置，不需要新增API Key。复刻口播必须补充并确认实际逐字稿，作品标题和描述不能代替口播全文。

内容写手另存独立待审稿，辅助能力另存“IP与写手→辅助分析结果”。任务保留素材、作者、选定评论、需求、写手与知识快照，原素材保持可追溯。

审稿页的“用写手改编”可选择5个默认内容写手；“用辅助写手分析”可分析当前稿件，输出报告。创建内容任务时，默认使用所选能力对应的默认写手，仍可选择已有专属写手。

## 知识自动增强

知识上传后须经过核验才能作为事实来源。每次新预览/新任务会检索目标IP当前已核验、未过期知识，并保存知识指纹、目录、ID和hash。新增知识、重新核验、归档或过期都会反映到当前有效知识状态，不自动发起付费模型调用。

默认写手卡片显示当前知识条数和IP增强版本。进入“规则与知识增强”可查看相对于最近规则变更时的知识快照的新增、变更和移出有效范围资料。

## 规则如何持续完善

1. 在素材或稿件中调用“写手进化”，按需选择真实改前/改后稿件，生成分析报告。
2. 在对应默认写手的“规则与知识增强”中选择目标IP，点击“提交完善建议”，填写改前/改后规则，也可关联该IP的分析报告。
3. 业务补充至少选择一条本IP有效知识；学习语感至少提供3篇独立根内容的真实改稿对照；人工表达偏好单独标明，不能作为事实证据。
4. 队员可提交候选，管理员或团队长采纳后生成新的IP增强版本。调用时自动使用当前有效规则。
5. 历史页可回退规则，回退操作生成新版本。知识失效时，其支持的规则自动暂停参与写作；回退规则不能恢复过期事实。

一个IP的价格、产品和案例不会写入共享基础模板。默认内容写手可“复制为专属写手”，再填写12问形成自己的表达体系。

## 权限和边界

默认目录面向已登录用户，调用仍逐条校验目标IP、素材、评论、需求与改稿证据。任务执行前后复核权限、有效知识和写手增强版本。私有来源的原文快照不会因为生成稿件而扩大可见范围。

当前采用按主题检索和已审核规则增强，不执行模型权重训练。知识更新自动作用于新任务；长期规则的变更须有证据并经审核。没有足够改稿证据时只产生建议，不声称写手已经学习成功。

## 验证

后端100项测试、浏览器16项回归与前端生产构建通过，覆盖默认8写手、素材调用、知识更新、规则审核/回退、IP隔离、真实受控队列与原有专属写手。未调用真实付费模型或TikHub。
